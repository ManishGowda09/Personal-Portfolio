# Manish - Portfolio

## Folder structure
```
portfolio/
├── index.html            <- page structure
├── assets/
│   ├── css/style.css     <- all styles and themes
│   ├── js/main.js        <- all interactions (theme, 3D model, circuit, dialogs, form)
│   ├── img/              <- your photos and project images
│   └── pdf/              <- your resume (New_resume.pdf)
└── .vscode/extensions.json
```

## Run in VS Code
1. Open the `portfolio` folder in VS Code (File > Open Folder).
2. Install the **Live Server** extension (VS Code will suggest it).
3. Right-click `index.html` and choose **Open with Live Server**.

The 3D CMOS model loads Three.js from the internet, so you need a connection to see it.

## Publish on GitHub Pages
Upload the same structure to the repository: replace `index.html`, the `css` and `js` folders, and keep `img` and `pdf`.
